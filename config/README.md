# Configuration guide

This folder is the normal editing surface for Duels2D. Runtime behavior lives in
`src/`; routine balance and presentation changes belong here.

## What to edit

| Change | File |
| --- | --- |
| One fighter's stats, weapon, sprite, hitbox, poses, or dialogue | `fighters/<fighter-id>.js` |
| Defaults shared by every fighter | `fighters/defaults.js` |
| Overall speed, collision damage, sound volume, or arena appearance | `game-settings.js` |
| Damage and health text appearance | `indicator-settings.js` |
| Sprite crop, scale, offset, or hitbox visually | Character Studio |

Do not hand-edit `fighter-config.js`. It applies shared defaults and converts the
grouped fighter definitions into the flat object expected by the runtime.
`sound-manifest.js` is generated by `node tools/generate-sound-manifest.js`.

## Fighter file layout

Each fighter has one definition:

```js
window.FighterDefinitions.push({
  id: "exampleguy",
  name: "Example Guy",
  color: "#ffcc00",

  combat: {
    maxHealth: 1200,
    speed: 8,
    baseDamage: 125,
    faceTarget: { mode: "always" },
    weapon: null,
  },

  body: {
    radius: 34,
    hitbox: { type: "box", width: 78, height: 112 },
    hitboxOffset: { x: 0, y: -15 },
  },

  presentation: {
    image: "assets/fighters/exampleguy/sprites/exampleguy.png",
    imageScale: 2,
    imageOffset: { x: 0, y: -10 },
  },

  lines: {
    ambient: ["Example line"],
  },
});
```

You only need to include values that differ from `fighters/defaults.js`.

`faceTarget.mode` accepts `never`, `always`, or `range`. Supported weapon types
are `projectile` and `proximity-melee`. Time values ending in `Ms` are
milliseconds; animation values ending in `Frames` are render frames.

## Adding a fighter

1. Copy the closest existing file under `config/fighters/` and give it a unique ID.
2. Add its assets under `assets/fighters/<fighter-id>/`.
3. Add its `<script>` tag after `fighters/defaults.js` in both `index.html` and
   `tools/character-studio/index.html`.
4. Run `node tools/validate-config.js`.
5. Open Character Studio for visual tuning. When saving, select that fighter's
   file; Studio will then auto-save changes for that fighter during the session.

## Before running the game

```bash
node tools/validate-config.js
```

The validator catches duplicate IDs, invalid ranges, unsupported modes and
weapons, missing required weapon fields, and missing image assets.
